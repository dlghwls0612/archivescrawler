# 서울·경기 기록관리 채용 레이더 (Records Job Radar)

서울·경기 지역의 **기록연구사(국가·지방직 임기제), 기록물관리전문요원, 아키비스트, 아카이브 운영직** 채용공고를 매일 자동 수집하고, 브라우저에서 편리하게 확인할 수 있는 정적 웹 대시보드입니다.

## 1. 수집 타깃 소스 (3대 핵심 축)
1. **사단법인 한국기록전문가협회 (KARMA)**: 전국 기록인 네트워크의 공식 채용공고 (국가기록원, 서울기록원, 국회기록원, 지자체 임기제 연구사)
2. **잡알리오 (ALIO)**: 수도권 소재 중앙 공공기관 및 공기업의 기록물관리전문요원 공고 (한국문화예술위원회 등)
3. **사람인 서울·경기 타깃**: 지자체 문화재단, 시설관리공단, 대학 기록관, 민간 아카이브 전문기업 공고

## 2. 디렉터리 구조
```
archivescrawler/
├─ sources.yaml          # 수집 설정, 직무 키워드 및 필터 규칙
├─ requirements.txt      # 의존성 라이브러리
├─ crawler/
│  ├─ main.py            # 메인 오케스트레이터 (취합, 중복제거, docs/data/jobs.json 생성)
│  ├─ karma.py           # 한국기록전문가협회 수집기
│  ├─ alio.py            # 잡알리오 공공기관 수집기
│  ├─ saramin.py         # 사람인 서울·경기 기록관리 수집기
│  ├─ classify.py        # 직무 적합성, 지역 판별, 자격요건, D-Day 상태 판정
│  └─ parsers.py         # 마감일 정규화 및 날짜 추출기
├─ docs/                 # GitHub Pages 서빙 폴더
│  ├─ index.html         # 기록관리 반응형 웹 대시보드
│  ├─ css/style.css      # 모던 UI 스타일시트
│  ├─ js/app.js          # 실시간 필터링/검색/정렬 클라이언트 스크립트
│  └─ data/
│     ├─ jobs.json       # 실시간 수집 결과 데이터
│     └─ jobs.js         # 로컬 file:// 열람 지원용 스크립트
└─ README.md
```

## 3. 로컬 실행 방법
```bash
# 의존성 설치
pip install -r requirements.txt

# 채용공고 수집 실행 (docs/data/jobs.json 생성)
python -m crawler.main --crawl
```

## 4. 웹 대시보드 확인
브라우저에서 `docs/index.html` 파일을 직접 열거나, GitHub Pages로 호스팅하여 확인할 수 있습니다.
- 지역 필터 (`전체`, `서울`, `경기`)
- 기록물관리전문요원 필수 공고 필터
- 마감된 공고 포함/제외 토글
- 실시간 키워드/기관명 검색
- D-Day 마감임박순 정렬
